Backup & restore

termux-sync ↗

A Python utility for backing up and restoring Termux packages, home files, configuration and shared libraries. Supports local storage, Google Drive via rclone, private GitHub repositories, scheduled backups and SHA-256 verification on restore.

Python 3.10+TermuxBackupSHA-256
