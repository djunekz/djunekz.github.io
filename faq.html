A quick reference for the person, the work and the projects.

Who is Djunekz?+

Djunekz is an independent software developer focused on CLI/TUI tooling, automation, release workflows and practical system utilities.

What does Djunekz build?+

Open-source developer tools and utilities, including Termux App Store, TDOC, termux-sync, AURA and PMCLI.

What is the main engineering focus?+

Reducing repetitive workflows, building terminal-first tools, designing for failure and keeping systems maintainable.

Which languages and platforms appear in the work?+

The public profile lists Python, Shell, Rust, C/C++ and JavaScript, with Linux, Termux on Android and GitHub Actions among the platforms.

Are the projects open source?+

The featured projects are published on GitHub. Visit each repository for its current license, source code, release status and contribution guidance.

How should I report a bug?+

Open an issue in the repository for the relevant project. Include the command, expected behavior, actual output and relevant environment details.

How can I get in touch?+

Use GitHub for project-related discussion or email for other inquiries.
