FAQ

Short answers to common questions.

Who is Djunekz?

A software developer and tooling architect (GitHub: djunekz) building open-source CLI/TUI tools, automation and release systems, and minimal infrastructure.

Are RedHat, mrxXx, Hmei7 and Anonymous the same person?

Yes. They are handles used by the same developer behind the GitHub account @djunekz.

What has Djunekz built?

AURA, PMCLI, TDOC, Termux App Store and termux-sync. See the projects page.

What languages and platforms does Djunekz use?

Python, Shell, Rust, C/C++ and JavaScript, on Linux, Termux (Android) and GitHub Actions.

Are the tools open source?

Yes. Source code lives on github.com/djunekz, and each project has its own repository.

How can I report a bug or ask a question?

Open an issue on the relevant GitHub repository, or send an email. See the contact page.

Does Djunekz work on hardware or embedded projects?

Yes. Embedded systems and hardware-to-software interfaces are a secondary area of interest.
