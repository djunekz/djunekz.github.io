About

One idea, repeated: build for the moment you are not there.

Djunekz is a software developer who builds open-source command-line (CLI) and terminal UI (TUI) tools, automation and release systems, and minimal infrastructure.

Tools should keep working, and keep telling the truth, when nobody is watching. That is the test every project is held to.

How the work is approached

Reduce the workflowFind the steps a person repeats and remove them.
Design for failure firstDecide what happens when it breaks, then build the happy path.
Ship it as a toolA small CLI or TUI that does one job and is easy to automate.
Release it automaticallyVersioning, packaging and publishing handled by pipelines, not people.
